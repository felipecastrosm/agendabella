# AgendaBella: front-end

SPA em Angular (com PWA) para a cliente agendar e para a equipe acessar o painel.

```bash
npm ci
npm start        # http://localhost:4200 (API em http://localhost:8000)
npm run build    # build de produção em dist/
```

Rotas: `/` (serviço e profissional), `/horario`, `/resultado`, `/equipe` (login) e `/equipe/agenda`.
